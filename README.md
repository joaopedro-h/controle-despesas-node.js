# 💰 Controle de Despesas (CLI) - Node.js

Sistema de **controle de despesas no terminal (CLI)** desenvolvido em **JavaScript utilizando Node.js**.  
O objetivo do projeto é permitir que o usuário registre, visualize e gerencie seus gastos diretamente pelo terminal.

Este projeto foi desenvolvido **100% de forma independente**, como prática de lógica de programação, manipulação de arrays, modularização e interação com o usuário no terminal.

---

# 🚀 Funcionalidades

O sistema permite:

- ➕ **Adicionar despesas**
- 📋 **Listar todas as despesas registradas**
- ✏️ **Editar despesas existentes**
- ❌ **Remover despesas**
- 🔎 **Filtrar despesas por categoria**
- 📈 **Mostrar a maior despesa**
- 📉 **Mostrar a menor despesa**
- 💰 **Calcular o total de gastos**
- 📊 **Calcular a média de despesas**
- 📑 **Gerar um relatório geral das despesas**

---

As despesas são registradas com:

- **ID**
- **Descrição**
- **Valor**
- **Categoria**

---

# 💾 Persistência de dados

Os dados são salvos em um arquivo **JSON**, permitindo que as despesas permaneçam armazenadas mesmo após fechar o programa.
